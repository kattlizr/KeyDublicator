# KeyDublicator
RFID (EM-Marine) and wired (Dallas, Cyfral, Metacom) key dublicator with arduino. Supports EM4305, T5577, RW-1990.1, RW-1990.2, TM-01, TM2004 and DC2000A protocols. 
There is a connections scheme in the project.

# Дубликатор ключей
Дубликатор бесконтактных (EM-Marine) и контактных (Dallas, Cyfral, Metacom) ключей на Ардуино. Поддерживает протоколы EM4305, T5577, RW-1990.1, RW-1990.2, TM-01, TM2004 и DC2000A.
Схема подключения есть в исходном коде.
