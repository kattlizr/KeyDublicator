# Дубликатор ключей
Дубликатор бесконтактных (EM-Marine) и контактных (Dallas, Cyfral, Metacom) ключей на Ардуино. Поддерживает протоколы EM4305, T5577, RW-1990.1, RW-1990.2, TM-01, TM2004 и DC2000A.
Схема подключения есть в исходном коде.

Ссылка на видео исходного автора: https://youtu.be/MvUK6XvUHIg

Подробный список деталей:
Arduino nano с type-c (можно и с mini-usb)
Подстроечный резистор 10Ком
Пассивный зуммер 5в (без генератора), можно достать со старого ПК
Светодиод 5мм с общим катодом
Кнопка без фиксации, нормально разомкнутая, можно любую, но для 3д распечатанного корпуса в исходном коде: https://ozon.ru/t/Hq90CkI
Выключатель с фиксацией, можно любой, но для 3д распечатанного корпуса в исходном коде: https://ozon.ru/t/mUdBCOz
Луза Touch Memory, можно любую, но для 3д распечатанного корпуса в исходном коде: https://ozon.ru/t/yeGgEoz
Адаптер питания от батареи крона 9в из экокожи (самый дешёвый)
